# 🎵 Carpeta de Audios

Coloca aquí tus archivos de audio (.mp3, .m4a, .ogg, .wav).

## Estructura recomendada

```
docs/
  audio/
    episodio-01.mp3
    episodio-02.mp3
    ...
```

## En el panel Admin

Al agregar un episodio, escribe la ruta relativa:
```
audio/episodio-01.mp3
```

## Notas
- Formatos soportados: MP3, M4A, OGG, WAV
- GitHub Pages tiene un límite de **100 MB por archivo**
- Para archivos más grandes, usa servicios como Google Drive o Dropbox y pega el enlace directo
