🔥 Configuración de Firebase Storage

¿Por qué Firebase?
Firebase Storage te permite subir tus archivos de audio directamente desde el panel admin, sin necesidad de usar GitHub. ¡Perfecto para archivos grandes!

Pasos para configurar:
1. Ve a console.firebase.google.com
2. Crea un proyecto → Activa Storage
3. Ve a Configuración del proyecto → Tus apps → Web → Copia la config
4. Pega los valores abajo y guarda
5. En Firebase Console → Storage → Rules → cambia allow read, write: if false; por allow read, write: if true; (solo para testing)

CLI (opcional): npm install -g firebase-tools
firebase login
firebase init storage
firebase deploy --only storage
Firebase conectado correctamente ✅

📁 Alternativa: Google Drive

Cómo usar Google Drive como hosting de audio:
1. Sube tu MP3 a Google Drive
2. Click derecho → Compartir → "Cualquiera con el enlace"
3. Copia el ID del archivo de la URL: https://drive.google.com/file/d/FILE_ID/view
4. Tu URL directa será:
https://drive.google.com/uc?export=download&id=FILE_ID 5. Pega esa URL en el campo "URL del audio" al crear el episodio
